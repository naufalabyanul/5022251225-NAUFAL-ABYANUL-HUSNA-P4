# Kesalahan yang ada pada program. 

1.	Pada baris ke-1—4, tidak ada kesalahan pada penulisan. Tapi jika program akan dijalankan, program akan mendapat peringatan ” incompatible implicit declaration of built-in function” karena kekurangan library. Library yang dibutuhkan adalah <math.h> agar compiler dapat memahami fungsi pow() pada baris ke-24. 

2.	Pada baris ke-16, ejaan nama tipe yang digunakan tidak sinkron pada penggunaan nama tipe pada baris ke- 18, 22, 27, 31, 54, 55, dan 62. Hal ini mengakibatkan error “unknown type name ‘Rekening’”. Untuk memperbaikinya, tambahkan huruf g untuk menjadi } Rekening; sehingga tipe dapat didefinisikan. 

3.	Pada baris ke-99, ejaan konstanta enum yang digunakan (SIMPL) tidak merujuk pada baris ke-7 sehingga menyebabkan error “undeclared identifier”. Untuk memperbaikinya, sesuaikan saja ejaannya seperti pada baris ke-7 agar dapat merujuk kepadanya.
